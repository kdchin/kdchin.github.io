2. haveCommonSquareFactors(n) [20 points]

Definitions:
  1. A common square factor of x and y is a number n such that n is a factor of both x and y, is also a perfect square, and is not 1.
  2. If you do not remember what a perfect square is, the first few are: 1 = 1*1, 4 = 2*2, and 9 = 3*3.
Examples:
  1. 36 and 100 have a common square factor of 4
  2. 36 and 99 also have a common square factor of 9
  3. 36 and 93 DO NOT have a common square factor
With this in mind, write the function haveCommonSquareFactors (haveCSF) which takes two any-valued real numbers x and y, and returns True if they have a common square factor, and False if not. Floats cannot have common factors, and we will say that 0 has no factors.

You may not use strings, lists, or recursion on this problem. Additionally, you may not use loops to check if a number is a perfect square, since there is a much faster way to do it without loops!

3. longestAlphabetRun(s) [25 points]

An alphabetical string is one in which all of the letters in the string are in increasing-or-equal alphabetical order without skipping any letters in the alphabet. For instance, "mnoopp" is an alphabetical string, but "mmoopp" is not. Write a function longestAlphabetRun (abbreviaton: lar) that takes in an all-lowercase string s and returns the number of unique letters in the longest alphabetical substring of s. If there is a tie in length, then return the number of unique letters in the alphabetically lower one. Examples:
  1. lar("arggghhijklol") returns 6 because the longest alphabetical substring is "ggghhijkl", which contains 6 unique letters.
  2. lar("abbbcdwxyyz") would return 3, since "abbbc" and "wxyyz" both are length 5, so we get the number of unique letters in "abbbc" (even though "wxyyz" has more unique characters).
You may assume that all letters in the string are lowercase. (Hint: you can compare strings using < or > just as you would numbers)

4. nthPalindromicNumber(n) [25 points]

A palindromic number is a positive number that is the same forwards and backwards. For example, 1, 22, and 696 are all palindromic numbers. With that in mind, write the functions nthPalindromicNumber(n) and isPalindromicNumber(n), which must function properly on its own too!. All single-digit numbers are palindromic, so nthPalindromicNumber(0) = 1. The first double digit palindromic number is 11, and nthPalindromicNumber(9) = 11. You may not use lists or strings in your solution. You may find it helpful to write a getKthDigit(n, k) function that returns the kth digit of a number n.

6. Reasoning Over Code [10 points]

What input makes the following function return True? Be certain to show your work, and also very clearly circle your answer! 
def g(s):
    x = 0
    for i in range(len(s)):
        c = s[i]
        if c.isdigit():
            assert(i == 0 or int(c) != x)
            x += int(c)
    return x
    
def roc(s):

    if g(s) != len(s): return False
